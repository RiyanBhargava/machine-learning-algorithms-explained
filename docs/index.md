## Built for two ways of learning

**Read here.** Search across topics, follow the chapter navigation, and use the table of contents to find a concept. No Python environment is needed to read the documentation.

**Experiment in Jupyter.** Download the original notebooks and run them from top to bottom. The website shows saved outputs; it does not run Python in the browser.

[Download the notebooks and images](downloads.md){ .md-button }

!!! note "One source of truth"
    The learning chapters are generated from the two notebooks. Updating a notebook and rebuilding the site updates its notes, code, figures, and saved results together.

## A useful reading order

1. Review the foundations: data, evaluation, and generalization before individual algorithms.
2. Follow the algorithm walkthroughs and explain each split, transformation, and metric.
3. Answer the practice questions aloud, then use the short answers to identify gaps.

This guide covers core classical ML and introduces broader topics. Synthetic demonstrations explain a method; their scores are not a leaderboard or a performance promise.
